# VÉLIA ATELIER — Luxury Furniture E-Commerce

Streamlined, self-contained luxury furniture store built with React, Tailwind CSS, Framer Motion, and Lucide Icons.

## Folder Summary
- **Total Files:** 56 files (optimized with zero `node_modules` bloat and zero duplicate images)
- **Ready-to-Run Website (`index.html`):** Double-click `index.html` directly in your browser (`file://`) or serve the root folder with any static web server (`http://`).
- **Assets (`assets/` & `images/products/`):** Compiled CSS/JS bundle and all 21 curated furniture lifestyle images.
- **Modular Source (`src/`):** Full React components, Tailwind configuration, and product data catalog.

## Quick Launch
Option 1 — Open directly:
Double-click `index.html`.

Option 2 — Local static server:
```powershell
python -m http.server 5173
```
Then open `http://localhost:5173/`.
